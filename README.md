## Como publicar (GitHub Pages)

1. Crie um repositório público no GitHub.
2. Carregue **todos os ficheiros** desta pasta para a raiz do repositório, mantendo a estrutura (pasta `assets/` ao lado de `index.html`).
3. **Settings → Pages** → Source: `Deploy from a branch` → Branch: `main` / `(root)` → **Save**.
4. Aguarde 1–2 minutos. O convite ficará disponível em:
   ```
   https://<o-seu-utilizador>.github.io/<nome-do-repo>/
   ```
