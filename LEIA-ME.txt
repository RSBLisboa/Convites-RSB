==============================================
INSTRUÇÕES PARA PUBLICAR NO SHAREPOINT
==============================================

1. Aceda ao site SharePoint do RSB.

2. Abra a biblioteca "Documentos" (ou crie uma nova
   biblioteca chamada "Convites").

3. ARRASTE TODA esta pasta para a biblioteca, mantendo
   a estrutura:

       Convite Substancias Perigosas.html   <-- ficheiro principal
       tweaks-panel.jsx
       assets/
           cabecalho.png
           barra.png
           montagem3.png
           rsb-brasao.png
           Logotipos.png

   IMPORTANTE: a pasta "assets" tem de ficar ao mesmo
   nível do ficheiro HTML, senão as imagens não aparecem.

4. Clique em "Convite Substancias Perigosas.html" para
   abrir num separador novo do browser.

5. Se o SharePoint mostrar o HTML como texto em vez
   de o renderizar, acrescente "?web=1" no fim do URL.

6. Copie o URL desse separador — esse é o link que cola
   no email a enviar aos convidados.
